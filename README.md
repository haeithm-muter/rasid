# رصيد (Rasid)

كاشف الاشتراكات المنسيّة من كشف الحساب البنكي. يقرأ ملف CSV **داخل المتصفح
بالكامل** ويكشف الرسوم المتكررة المنسية. **صفر رفع بيانات لأي خادم.**

> هذا المستودع يحتوي حالياً **الجزء 1 فقط: التأسيس وطبقة الإدخال**.
> محرك الكشف (الجزء 2) والواجهة (الجزء 3) لم يُبنيا بعد.

---


## العقد بين الأجزاء

كل شيء ينتهي إلى هذا النوع، وعليه يبني الجزءان 2 و3:

```ts
type Transaction = {
  date: string;        // ISO صارم: YYYY-MM-DD
  description: string; // الوصف الخام كما ورد (بلا تنظيف)
  amount: number;      // موجب دائماً
  currency: string;    // ISO-4217 بحروف كبيرة
  direction: 'debit' | 'credit';
};
```

نقطة الدخول الموحّدة:

```ts
import { importCsvBytes } from './src/core/importCsv';

const { transactions, skipped, adapter, encoding } = importCsvBytes(bytes);
```

`skipped` يحمل كل صف تعذّر تحويله مع سبب مقروء بالعربية — الملف لا يفشل كاملاً
بسبب صف واحد تالف.

## إضافة بنك جديد

**ملف واحد جديد، بلا تعديل أي كود قائم.** أنشئ
`src/adapters/<اسم-البنك>.adapter.ts`:

```ts
import { createBankAdapter } from './createBankAdapter';

export default createBankAdapter({
  id: 'my-bank',
  label: 'اسم البنك',
  dateFormat: 'DD/MM/YYYY',      // أو 'MM/DD/YYYY' أو 'YYYY-MM-DD' أو 'auto'
  defaultCurrency: 'SAR',
  columns: {
    date: ['التاريخ', 'Date'],
    description: ['البيان', 'Description'],
    currency: ['العملة'],         // اختياري
  },
  amount: {
    kind: 'split',                // عمودان منفصلان
    debit: ['مدين'],
    credit: ['دائن'],
  },
  // أو عمود واحد مُشار:
  // amount: { kind: 'signed', amount: ['المبلغ'], direction: ['نوع العملية'] },
});
```

يلتقطه `import.meta.glob` تلقائياً في `src/adapters/index.ts`.

المحوّلات الحالية: `alrajhi`، `snb`، `chase`، `enbd`.

### كيف يختار الكاشف التلقائي

`detectAdapter` يعطي كل محوّل درجة = عدد الأعمدة التي تعرّف عليها، ويفوز الأعلى.
المقارنة **بالتساوي التام بعد التطبيع** لا بالاحتواء، حتى لا يبتلع `Amount`
عموداً أخص مثل `Debit Amount`.

عند الفشل يُرمى خطأ يحمل قائمة المرشّحين:

- `NoMatchingAdapterError` — لا يطابق أي محوّل
- `AmbiguousAdapterError` — تعادل محوّلان

كلاهما مصمَّم ليعرض للمستخدم قائمة اختيار يدوي، ويُمرَّر اختياره عبر
`importCsvText(text, { adapterId })`.

## معايرة توحيد أسماء التجار

الثابت الوحيد الذي يستحق المعايرة معلن في أعلى
`src/core/merchantNormalizer.ts`:

```ts
export const DEFAULT_SIMILARITY_THRESHOLD = 0.82;
```

- **رفعه** → مجموعات أنقى، لكن تفويت أشكال متباعدة لنفس التاجر
- **خفضه** → دمج أوسع، لكن خطر خلط تجّار مختلفين

التجميع يستخدم **ليفنشتاين مطوّرة من الصفر** (بلا مكتبة خارجية) مع خوارزمية
"قائد ومنضمّون" لمنع التسلسل الذي يبتلع تجّاراً متباعدين في مجموعة واحدة.

كل الأوصاف الأصلية محفوظة في `cluster.variants` — لا شيء يُفقد، ليتحقّق
المستخدم يدوياً في الواجهة لاحقاً.

**حدود معروفة ومقصودة:** `AMAZON` و`AMAZON PRIME` لا يتجمّعان، وكذلك `STC`
و`STC PAY` — لأنهما اشتراكان مستقلان بسعرين مختلفين. الفصل هنا مطلوب لا خطأ.
